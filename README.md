Simple Quote App

A simple quote application built to gain hands-on experience with AWS cloud services.


Technologies

HTML, CSS, JavaScript

Amazon CloudFront – Planned content delivery.

Google Gemini – Used only to assist with CSS styling and visual design. Application functionality and logic were developed independently.

Built to learn AWS static website hosting, cloud storage, and content delivery.
